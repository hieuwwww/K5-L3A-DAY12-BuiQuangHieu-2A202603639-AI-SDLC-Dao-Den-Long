# Phase 1 Game Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a playable first-night Three.js game and deterministic headless CLI conforming to PRD-0 Test Contract v1.0.

**Architecture:** A pure JavaScript simulation module owns all gameplay state and advances at fixed 60 Hz. A Node CLI parses contract/scenario/inputs and writes JSONL; a browser Three.js client renders the same simulation state and translates keyboard/mouse controls into simulation inputs.

**Tech Stack:** Node.js ES modules, Three.js, HTML/CSS, Node built-in test runner.

**Spec:** `docs/superpowers/specs/2026-11-20-phase-1-design.md`; source requirements supplied by user as PRD-0 and Test Contract v1.0.

## Global Constraints
- Headless runs without window or GPU, uses exact 60 ticks/second semantics, and exits 0 on success, 2 for malformed scenario/inputs, other nonzero on runtime errors.
- Contract v1.0 requires deterministic output for identical seed, scenario, and inputs.
- Player starts at `[0,0,0]`; distances are horizontal XZ; positions are rounded to 3 decimals in JSONL.
- Preserve the specified CLI flags, snapshot/event/end JSONL records, and input edge-trigger rules.
- Run on macOS/Linux; provide install/build/run instructions in at most three commands.

## Review Focus
- Malformed JSON or invalid frame fields: reject with exit code 2 and stderr message; test in CLI validation task.
- Sparse inputs and frames at tick 0 / adjacent ticks: retain omitted controls and trigger actions only on false→true; test in input/simulation task.
- Terminal win/loss mid-request: stop immediately and emit exactly one final end record; test in simulation/CLI task.
- Seeded random spawning and generated IDs: byte-identical output for repeated invocation; test in determinism task.
- Scenario-prelit lanterns and supplied entities: initialize without events/score, preserve listed IDs and defaults; test in scenario task.
